### Featured projects

#### 🔬 [llm-perf-proxy](https://github.com/ghpotter/llm-perf-proxy)
> An async performance and cost observability proxy for LLMs.

Sits transparently in front of Ollama, OpenAI, or Anthropic — streams responses to the client with zero added latency while capturing token throughput, time-to-first-token, and per-request cost estimates asynchronously into SQLite. Includes a live Chart.js dashboard at `GET /` and a REST metrics API with time-series bucketing.

`Python` · `FastAPI` · `SQLite` · `Docker` · `asyncio`

---

#### 📷 [WordFido](https://github.com/ghpotter/WordFido)
> Android app that searches for words in a live camera feed.

Point your phone at any text — a book, a menu, a whiteboard — and WordFido uses on-device OCR to find and highlight words in real time. Built in Kotlin with Android ML Kit.

`Kotlin` · `Android` · `ML Kit` · `Camera2`
